\textbf{PROGRESSION \& RECOVERY}\par\vspace{0.6mm}
\begin{minipage}[t]{0.485\linewidth}\raggedright
\textbf{Reps:} Each printed target applies to all sets. Add 1 rep per set after completing the target in every set; otherwise repeat. For unilateral work, complete both arms/sides.\par
\textbf{Weight:} Increase once all sets reach the range maximum; restart at minimum. If too heavy, record actual reps and rebuild.\par
\textbf{Effort:} Main work: ~1 RIR (last set 0--1 possible). Finisher: keep technique consistent; do not chase failure.
\end{minipage}\hfill\begin{minipage}[t]{0.485\linewidth}\raggedright
\textbf{Rest:} Alternate sets with your partner; allow extra recovery as needed.\par
\textbf{Plateaus:} Technique, control and ROM gains count. If half or more movements stall or regress for 3 consecutive sessions, skip the next session, then resume.
\end{minipage}
