\textbf{PROGRESSION \& RECOVERY}\par\vspace{0.6mm}
\begin{minipage}[t]{0.485\linewidth}\raggedright
\textbf{Reps:} Add one total repetition to Sets 1--2 per successful session (8/8, 9/8, 9/9). In 3-set mode, Set 3 copies Set 2. Progress duplicate movements by slot; repeat missed targets.\par
\textbf{Weight:} Increase only when all prescribed sets reach the range maximum; restart at its minimum. If too heavy, record actual reps and rebuild.\par
\textbf{Effort:} Aim for about 1 RIR; final set may reach 0--1 RIR. Prioritise technique.
\end{minipage}\hfill\begin{minipage}[t]{0.485\linewidth}\raggedright
\textbf{Rest:} Alternate sets; rest while your partner works. Equipment changes add recovery. Pause if required for safe technique.\par
\textbf{Plateaus:} Off days and isolated stalls are normal. Better technique, control, or range of motion (including fuller partials) counts as progress. If half or more of the movements stall or regress across three consecutive sessions, skip the next planned session for recovery, then resume.
\end{minipage}
